ICOForge Open Data

Reproducible pixel measurements for image-to-ICO conversions. All data is generated by real browser canvas rasterization and verified with decoded pixel counts.

Datasets

  • WebP to ICO alpha measurement — 5 sizes, corner alpha = 0 at every size
  • SVG to ICO rasterization — direct 16/32/48 px pixel counts
  • Favicon size checklist — Windows, iOS, Android, browser

Documentation

  • How to reproduce the WebP-to-ICO alpha test
  • How to reproduce the SVG-to-ICO rasterization test

Source

All measurements come from the tools at icoforge.com. Source images and ICO output files are available for download on each tool page.
