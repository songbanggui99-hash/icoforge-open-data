# ICOForge Open Data

Reproducible pixel measurements for image-to-ICO conversions. All data is generated by real browser canvas rasterization and verified with decoded pixel counts — not estimates.

## What's here

### `data/webp-to-ico-alpha-measurement.csv`
Five ICO sizes (16–128 px) generated from a transparent WebP source. Every corner pixel has alpha = 0, proving that WebP transparency survives the ICO conversion. Columns: ICO size, ICO bytes, PNG payload bytes, transparent / opaque / partially transparent pixel counts, corner alpha values for all four corners.

### `data/svg-to-ico-rasterization-direct16.csv`
SVG gear icon rasterized directly at 16, 32 and 48 px. Shows painted pixel counts and ink coverage. Useful for understanding how vector strokes behave at small sizes.

### `data/favicon-size-checklist.csv`
Complete favicon size reference: Windows ICO sizes (16–256), iOS Apple Touch (180), Android (192, 512), and generic browser tab sizes. Each row has the platform, format, and whether it's recommended or optional.

## Source

All measurements come from the tools at [icoforge.com](https://icoforge.com). The source images and full ICO output files are available for download on each tool page, so you can reproduce every number yourself.
